# Block 0: Foundation

## Scope
Set up the core project architecture, database, and design system.
- Frontend: Vite + React + TS + Tailwind
- Backend: Express + SQLite + TypeScript
- Database: 11 tables initialized in SQLite

## Owned Paths
- `frontend/`
- `backend/`
- `backend/src/db.ts`
- `frontend/tailwind.config.ts`

## Exit Criteria
- Vite app runs
- Express server runs and initializes SQLite
- Tailwind configured with Swasthya theme
